# إنجليزي تخصصي — نسخة عبدالمنعم الشخصية (Specialized English)

أداة اكتساب لغة إنجليزية تفاعلية شخصية: استماع أولًا، تظليل، كلام وتصحيح، رفيق محادثة مكتوب،
حوار مفتوح اختياري بمفتاح Google Gemini المجاني الخاص بالمستخدم، ألعاب سريعة، مراقب وخطة يومية،
سلّم CEFR من A1 إلى C2 باختبارات عبور إلزامية (≥٧٠٪)، وميزات حية مجانية (BBC، قاموس حي، ويكيبيديا المبسّطة).

- تُحفظ البيانات على جهاز المستخدم فقط (localStorage) — لا خادم ولا حسابات.
- مفتاح Gemini (إن وُضع) يبقى في متصفح المستخدم ويُرسل لخوادم Google فقط.
- المحتوى أصلي بالكامل؛ الروابط الخارجية إحالة لمصادر مجانية (BBC / VOA / YouGlish / Forvo).
